# 调试与验证

## 面板没有出现

确认 Tampermonkey 已启用脚本，页面地址符合脚本头部 `@match` 范围。刷新顶层课程页面，面板仅在顶层运行。

## 找不到视频

等待章节和播放器加载后点击“重新扫描播放器”。脚本会自动递归扫描同源 iframe。状态中的“跳过不可访问框架”说明有框架无法读取；跨域框架不会被强行访问。

## 视频仍然互相暂停

检查“已解除互斥”数量是否等于视频总数。未找到 `Ext.getCookie` 时暂时不能安装 Hook，自动扫描会继续重试。

如果已经安装 Hook 仍暂停，需重新定位播放器暂停来源。平台可能使用其他互斥机制或正常的互动、错误处理逻辑。

## 检查真实播放状态

点击“一键开始”后，观察面板的“正在播放”数量。持续观察原播放器时间是否推进，而不只看播放按钮外观。在对应同源播放器 iframe 的开发者工具上下文中，可以执行：

```js
[...document.querySelectorAll('video')].map(video => ({
    paused: video.paused,
    ended: video.ended,
    time: video.currentTime,
    muted: video.muted
}));
```

间隔约五秒再次执行，比较 `time` 的增量。点击“全部暂停”后确认各视频 `paused` 为 `true`、播放时间停止推进。

## 启动失败

浏览器自动播放策略、资源未加载或播放器错误均可能拒绝 `play()`。脚本默认静音并报告失败数量；可以检查原播放器提示，或先手动点击播放器后再重试。

## 服务端任务点

浏览器视频播放结束不等于平台任务点完成。请在平台页面核对真实进度。本项目不提供进度、时长、心跳或任务状态伪造功能。
